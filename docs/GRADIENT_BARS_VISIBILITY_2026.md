# Vérification de visibilité — Gradient Bars

Le 26 août 2026, le hero public a été contrôlé après renforcement de la texture Gradient Bars.

| Surface | Résultat vérifié |
| --- | --- |
| Desktop 1355 × 608 | Les dix bandes evergreen, leurs séparations et leur profondeur sont nettement perceptibles derrière le contenu. Le titre, les CTA et l’aperçu caisse demeurent lisibles. |
| Mobile 390 × 844 | Les bandes restent visibles dans le hero sans gêner le menu, le texte, le CTA principal ni la preuve produit. |

La texture est strictement décorative et garde son rendu statique lorsque la préférence système de mouvement réduit est activée.
