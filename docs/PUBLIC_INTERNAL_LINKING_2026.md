# Maillage interne public — EASYSTOR

## Architecture publiée

| Point d’entrée | Accès proposés |
| --- | --- |
| Landing `/` | Navigation « Guides pratiques », carte hero vers le hub, liens contextuels dans les sections Migration et Hors connexion, footer. |
| Hub `/guides` | Les deux guides pratiques, retour à l’accueil et CTA d’inscription. |
| Guide migration | Accueil, hub des guides, guide hors connexion et inscription. |
| Guide hors connexion | Accueil, hub des guides, guide migration et inscription. |

Le sitemap public référence désormais la landing, le hub et les deux guides. Ainsi, aucune ressource éditoriale publique ne dépend d’un lien isolé depuis une seule section.

## Contrôle visuel

| Surface | Résultat vérifié |
| --- | --- |
| Desktop 1280 × 720 | Les deux cartes de guide sont visibles côte à côte et disposent de CTA explicites. |
| Mobile 390 × 844 | Les deux cartes passent en colonne, sans lien caché ni chevauchement, avec un accès lisible à l’inscription. |
